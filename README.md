## Adding a project or map

The Projects section is generated from `projects-data.js`. To add a new map (or any project), copy one object
in the `PROJECTS` list, point `cover` at a small JPG thumbnail (about 1000 px wide) and list the full-size images
in `gallery`. Filter chips, cards and the gallery lightbox update automatically. The format is documented at the
top of `projects-data.js`.
